active work to [GitHub Issues](https://github.com/Codeseys-Labs/audio-graph/issues).

[`2214e0f`](https://github.com/Codeseys-Labs/audio-graph/commit/2214e0f).

Look up historical `audio-graph-xxxx` IDs from code comments, commit messages,
ADRs, and documentation in [`issues.jsonl`](issues.jsonl). The 565 closed seeds
were retained here and excluded from the migration. See the
[seed-to-issue mapping](SEEDS_TO_ISSUES.md) for the 365 migrated active seeds.
